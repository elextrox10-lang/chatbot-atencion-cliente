# Sistema de Atención al Cliente Automatizado (Chatbot con OpenAI)

Este proyecto implementa un asistente virtual inteligente para atención al cliente utilizando la API oficial de OpenAI. El chatbot es capaz de entender consultas de soporte, ofrecer recomendaciones de productos y simular consultas a una base de datos interna de la empresa.

## Requisitos Previos

- Python 3.8 o superior instalado en tu sistema.
- Una clave de API válida de OpenAI (`OPENAI_API_KEY`).
